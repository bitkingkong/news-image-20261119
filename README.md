## How it is made

`entry.png` (1024×1024, PNG) is drawn with Python PIL: a masthead naming
the date, one AI illustration strip with no text in it, and five story rows
with colour chips, kickers, headlines and one-line decks. `main.ts` (Node 22,
standard library only, no network) copies `entry.png` to `/output/entry.png`.
